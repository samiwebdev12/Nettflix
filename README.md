# Nettflix

An unofficial Nettflix (Netflix-style) UI clone — a static, responsive landing
page with a trending movies carousel, FAQ accordion, and a sign-in page.

Created by **Sami Ullah** for educational and portfolio purposes. Not
affiliated with or endorsed by Nettflix.

## Tech

Pure static site: HTML, CSS, and vanilla JavaScript. No build step, no
dependencies, no external CDNs — all assets are local.

## Run locally

There is no build step. Open `index.html` directly, or serve the folder:

```bash
npx serve .
```

## Deploy to Vercel

1. Push this repo to GitHub.
2. In the [Vercel dashboard](https://vercel.com/new), click **Add New Project**
   and import the GitHub repo.
3. Vercel auto-detects a static site — no build command or settings needed.
   Just press **Deploy**.

Every push to the default branch redeploys automatically.
