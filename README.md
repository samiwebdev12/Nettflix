# Nettflix

An unofficial Nettflix (Netflix-style) UI clone — a static, responsive landing
page with a trending movies carousel, FAQ accordion, and a sign-in page.

Created by **Sami Ullah** for educational and portfolio purposes. Not
affiliated with or endorsed by Nettflix.

## Tech

Pure static site: HTML, CSS, and vanilla JavaScript. No build step, no
dependencies, no external CDNs — all assets are local.
